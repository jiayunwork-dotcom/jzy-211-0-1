# 二极管晶圆参数提取系统

探针台分块上传每颗二极管的正向 I–V 扫描；后台逐颗提取 **饱和电流 Is、
理想因子 n、串联电阻 Rs**，网页以晶圆图查看参数分布、点开单颗看拟合与残差，
并支持判级规则的版本化与新旧版本对比。

## 模型

单指数二极管 + 串联电阻：

```
I = Is · ( exp( (V − I·Rs) / (n·Vt) ) − 1 )
Vt = k_B·T/q        # 300 K 时 Vt ≈ 25.852 mV
```

端电压方程 `V = n·Vt·ln(1+I/Is) + I·Rs` 对 I 单调，代码用向量化牛顿法
求隐式根（`app/diode.py`）。参考校验：

| 条件 | 参考值 |
|---|---|
| Vt @ 300 K | 25.852 mV |
| Is=1e-14 A, n=1, Rs=0, V=0.6 V | I ≈ 1.201e-4 A |
| Is=1e-14 A, n=2, Rs=0, V=0.6 V | I ≈ 1.096e-9 A |

## 参数提取方法（先粗估、再整体精修）

实现在 `app/extraction.py`：

1. **校验**：点数 ≥ 5、电压严格单调递增、无负电流/零电流/非数值、
   温度 ∈ [200, 500] K。不合法直接拒收（`ok=False` 并写明原因）。
2. **底噪剔除**：电流低于 `NOISE_FLOOR`（默认 1e-12 A）的点不参与拟合——
   低电流段被漏电与仪器底噪主导，不反映理想结的指数规律。剔除后点数 < 5
   或电流跨距 < 3 个 decade，判提取失败。
3. **粗估**：低电流段（前 35% 点）对 `ln I ~ V` 线性拟合给 n、Is；
   高电流段（后 40% 点）用理想指数的压降差 ΔV ≈ I·Rs 拟合 Rs 初值。
4. **精修**：全部有效点的 `log10 I` 残差做有界非线性最小二乘
   （SciPy `least_squares` / TRF，解析雅可比），参数取对数保证为正。

**拟合质量**用 log10(I) 的 RMSE（单位 decade）衡量，超过阈值
`FIT_RESIDUAL_THRESHOLD`（默认 **0.10 decade**，约 26% 相对偏差）标记为
**提取失败**，前端打 ✕，不会只丢一个可疑数字。

### Rs 在什么情况下会给出错误结果

* **扫描没进入串联电阻主导区**（高电流点的 I·Rs 与 n·Vt 同量级或更小）：
  Rs 在数据中不可辨识，真值为 0 与真值很大在该数据上几乎无法区分。
  此时 `rs_reliable=false`，单颗页面会提示“Rs 仅供参考”。判据是
  数据在最高点对 Rs 的杠杆 `I_max·n·Vt`（V/Ω），低于 1e-5 即不可辨识。
* **漏电/并联电导延伸到中电流区**：模型没有并联电导项，漏电会被部分
  吸进 Rs 与 n，使 Rs 偏大。底噪剔除只能压掉最低电流段。
* **大注入/自热**：物理上偏离单指数，同样被误算成欧姆压降。

## 数据接入与复测合并（确定性保证）

探针台每测完一段上传一个块（`POST /chunks`），块可任意顺序、任意粒度、
可重复。原始扫描全部落库在 `raw_scans`（事实来源），每颗管芯的
“最终有效扫描”由确定规则选出：

1. 通过结构校验（含坐标范围）的扫描优先于被拒收的扫描；
2. 同为有效时取 `tested_at` 较晚者（复测以晚为准）；
3. 时间相同取较晚上传（行 id 较大）。

### 增量更新 vs 整片重算

本系统选择**作业时对整片最终有效数据全部重算**（`app/processing.py`），
不为每个块做增量更新：

* 复测会改变任意一颗的输入，乱序到达时增量中间态没有意义；整片重算只
  依赖合并后的最终数据，**天然保证“无论多少块、什么顺序、多少次复测，
  结果与一次性提交完全相同”**（有测试锁定，见下）。
* 单颗拟合是纯函数、互相独立，几千颗秒级完成。
* 代价：上传不即时更新结果，需要发起一次作业；作业耗时正比于整片规模
  而非本块大小。换来的是确定性与简单的取消/回滚语义。

## 作业与取消

作业在进程内线程池运行（`app/scheduler.py`），状态写 PostgreSQL，页面轮询：

* 计算阶段在每颗管芯边界检查取消标志；
* **唯一的结果写入点是整片算完后的单事务**（`DELETE` + 批量 `INSERT`，
  `app/processing.persist_results`）。取消时纯计算结果直接丢弃、
  **绝不提交，因此不会留下半截晶圆图**。

## 判级与规则版本

规则版本（`app/grading.py`）包含每个参数的 `[lower, upper]` 与
“提取失败算不算不良”开关。上限 < 下限等非法规则拒收。等级：

* `pass`：参数全部在限内；
* `fail`：越界，或提取失败且规则规定失败算不良；
* `ungraded`：提取失败且失败不算不良（不计入良率分母）。

每颗结果绑定所依据的 `rule_version_id`。发布/激活新版本后对已有结果
**只重判级、不重新拟合**（`app/queries.regrade`）；版本对比接口与页面
展示哪些管芯等级变化、良率如何变化。

## 拒收清单（均记录原因）

* 扫描点 < 5 个
* 电压不严格单调
* 负电流、零电流或 NaN/Inf
* 测试温度不在 200–500 K
* 管芯坐标超出该晶圆登记的列×行范围
* 规则里上限 < 下限（创建规则版本时 400）

## 模块划分（后端各自成模块）

```
app/
  diode.py        # 物理模型：热电压、隐式求电流
  extraction.py   # 参数提取、校验、坏点/底噪剔除、残差与失败判定
  ingestion.py    # 分块接入、入库校验、复测合并（DISTINCT ON）
  processing.py   # 整片纯计算、汇总（中位数/分位数/良率）、原子落库
  scheduler.py    # 后台作业、进度、取消
  grading.py      # 规则校验、判级
  db.py           # 连接池、建表
  queries.py      # 晶圆图/单颗明细/重判级/版本对比
  routers/        # batches, wafers, jobs, rules 路由
  schemas.py      # Pydantic 模型
  main.py         # FastAPI 装配
```

前端按页面拆在 `frontend/src/pages/`，可复用部件在 `components/`
（晶圆网格 `WaferMapGrid`、拟合/残差图 `FitPlot`）。

## 运行

```bash
docker compose up --build
# 前端 http://localhost:8080  后端文档 http://localhost:8000/docs
```

典型流程：建批次 → 登记晶圆（列×行）→ 在晶圆页粘贴 JSON 块多次上传 →
发起作业 → 看晶圆图/点开管芯 → 在规则页发布新版本、对比等级。

上传块 JSON 形如：

```json
[
  {
    "x": 0, "y": 0, "temp_k": 300,
    "tested_at": "2026-10-01T12:00:00Z",
    "voltage": [0.05, 0.06, "..."],
    "current": [1.2e-10, 1.5e-10, "..."]
  }
]
```

## 测试

```bash
cd backend
pip install -r requirements-dev.txt
pytest                       # DATABASE_URL 指向一个可建表的 PG16
```

`tests/conftest.py` 默认连 `host=/tmp user=postgres dbname=diodetest`，
可用 `DATABASE_URL` 覆盖；库不可达时集成测试自动 skip。覆盖：

* 三个参考值（热电压、n=1/n=2 @0.6 V）
* 合成曲线（叠加噪声）三参数在容差内还原；无噪声极限精确还原
* Rs=0 的退化情形；Rs 不可辨识时 `rs_reliable=false`
* 提取失败判定（残差超阈值）与全部拒收原因
* **分块乱序 + 多次复测后，逐颗结果与一次性处理逐字段相同**
* 取消不落库、不留半截结果
* 规则版本切换只改判级不改参数、版本对比、规则非法拒收
* 全 HTTP 流程（TestClient + 真实 PG）

容差（合成曲线测试）：Is ±30%，n ±0.05，Rs（真值>0 时）±20%。
